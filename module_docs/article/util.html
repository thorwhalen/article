article.util

Thin, dependency-light utilities shared across the package.

Nothing here knows about platforms or pipelines — these are general helpers: logging, human-like async pacing (so automating your own account doesn’t trip automated-traffic heuristics), atomic JSON IO for the state store, and the canonical-URL guard that every secondary adapter calls so the SSOT link is never silently dropped.

Side-effecting primitives (sleeping, the clock, the RNG) are injected as keyword-only parameters so the helpers stay deterministic under test.

article.util.atomic_write_json(path: str | PathLike, data: Any, *, indent: int = 2) → None[source]

Write data as JSON atomically (temp file + os.replace).

Creates parent directories as needed. The temp-then-replace dance means a crashed write never leaves a half-written state file behind.

article.util.get_logger(name: str = 'article') → Logger[source]

async article.util.human_delay(min_seconds: float, max_seconds: float, *, _sleep: ~typing.Callable[[float], ~typing.Awaitable[None]] = <function sleep>, _rand: ~typing.Callable[[float, float], float] = <bound method Random.uniform of <random.Random object>>) → float[source]

Sleep a randomized, human-like interval; return the delay used.

Used between scripted browser actions so automation of one’s own account paces like a person. The sleeper and RNG are injectable for deterministic tests:

>>> import asyncio
>>> async def _no_sleep(_): pass
>>> asyncio.run(human_delay(0.5, 0.5, _sleep=_no_sleep))
0.5

article.util.require_canonical_url(platform: str, canonical_url: str | None) → str[source]

Return canonical_url or raise — the SSOT link is never optional.

Every secondary adapter calls this first so a missing canonical link fails loudly instead of silently emitting a self-canonical post.

>>> require_canonical_url("medium", "https://x.substack.com/p/y")
'https://x.substack.com/p/y'
>>> require_canonical_url("medium", None)
Traceback (most recent call last):
...
article.base.AdapterError: medium: canonical_url is required for syndication but was missing
article.util.run_sync(coro: Awaitable[T]) → T[source]

Run an async coroutine to completion from sync code (CLI entry points).

A thin, named wrapper over asyncio.run() so the dispatch-to-interface seam is obvious and easy to swap (e.g. for an existing event loop later).
