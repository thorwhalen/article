article.adapters

Built-in platform adapters.

Importing this package has the side effect of registering every built-in adapter in article.registry. The top-level article package imports it, so the registry is populated as soon as article is imported.

To add a platform: drop a new module here that decorates an async function with @register_adapter("<name>"), then import it below. No core code changes.
